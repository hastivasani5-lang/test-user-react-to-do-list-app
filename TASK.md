# React To-Do List App

**Difficulty:** Junior  
**Deadline:** 3 days

## Scenario

Create a simple To-Do List application using React, where users can add, remove, and mark tasks as completed. The application should store tasks in local storage and display them in a list. The user should be able to filter tasks by their completion status.

1. Implement a text input field to add new tasks
2. Create a list to display all tasks with their completion status
3. Add functionality to remove and mark tasks as completed
4. Use React hooks to manage state and side effects
